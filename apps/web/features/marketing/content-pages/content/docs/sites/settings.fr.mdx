Accédez aux paramètres du site depuis la barre latérale de l'éditeur. Les actions de base sont également disponibles depuis la carte du site dans le tableau de bord.

## Général

**Nom** — Le nom d'affichage du site. Affiché dans le tableau de bord, l'éditeur et optionnellement dans la navigation du site. Peut être modifié à tout moment.

**Identifiant** — Le segment de chemin qui identifie ce site dans l'URL :

```
https://votre-equipe.baseblocks.dev/[identifiant-site]
```

<Callout type="info">
  L'identifiant du site est choisi à sa création et ne peut pas être modifié actuellement depuis les paramètres.
</Callout>

**Favicon** — Importez la petite icône utilisée dans l'onglet du navigateur du site publié.

## En-tête et navigation

Choisissez d'afficher le logo et le nom dans la barre latérale publiée, ainsi que la recherche dans l'en-tête toujours visible.

## Domaines personnalisés

Ajoutez un nom d'hôte comme `docs.exemple.com` dans la section Domaine personnalisé. BaseBlocks indique l'enregistrement DNS requis et son état de vérification. Une fois le DNS configuré et vérifié, le site publié s'ouvre à la racine du domaine avec TLS géré automatiquement.

## Visibilité

Contrôle qui peut voir le site publié :

| Mode | Qui peut voir |
|---|---|
| Public | Toute personne avec l'URL |
| Privé | Membres de l'équipe connectés uniquement |

L'accès par lien et l'accès par mot de passe ne sont pas encore implémentés.
Voir [Visibilité du site](/docs/publishing/visibility) pour le comportement
complet d'accès et d'indexation.

## Supprimer un site

La suppression est disponible depuis les contrôles du site après le retrait de
tous les domaines personnalisés. Elle supprime les enregistrements de base de
données du site, notamment les pages, le contenu, les métadonnées des documents
et ressources, les bibliothèques, l'état de publication et les entrées de
recherche.

<Callout type="error">
  La suppression d'un site est permanente et ne peut pas être annulée. Il n'y a pas de chemin de récupération après la suppression.
</Callout>
