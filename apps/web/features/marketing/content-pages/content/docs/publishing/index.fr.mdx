## État de publication

Un site est soit **publié**, soit **non publié**. La publication crée une version
immuable à partir du brouillon enregistré et active cette version atomiquement.
La visibilité détermine ensuite si la surface en ligne est publique ou réservée
aux membres connectés de l'équipe. Le retrait coupe entièrement la surface en
ligne.

## Publier

<Steps>
<Step>

### Construire votre site

Créez des pages et modifiez le contenu. Les changements sont enregistrés automatiquement.

</Step>
<Step>

### Publier

Cliquez sur **Publier** dans l'en-tête de l'éditeur. Un site Public devient
accessible à tous. Un site Privé devient accessible uniquement aux membres
authentifiés depuis son adresse BaseBlocks générée.

</Step>
</Steps>

## Historique des versions

Ouvrez **Historique des versions** pour consulter les changements d'une version
publiée. Choisissez **Définir comme version en ligne** pour restaurer une version
précédente sans modifier le brouillon. Choisissez **Restaurer comme brouillon**
pour copier cette version dans l'éditeur, puis publiez le brouillon restauré.

## Retirer un site

Ouvrez le menu de déploiement et choisissez **Retirer**. L'URL générée et le
domaine personnalisé cessent de servir le contenu jusqu'à la prochaine
publication. Le contenu enregistré dans l'éditeur n'est pas supprimé.
