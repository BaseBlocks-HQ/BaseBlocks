title: Visibilité du site
description: Choisissez si un site publié est public ou réservé aux membres connectés de l'équipe.
icon: Eye
---

La visibilité contrôle qui peut lire un site **publié**. Elle ne publie ni ne
retire le site par elle-même. Ce réglage se trouve dans **Paramètres du site →
Visibilité**.

## Public

Tout le monde peut ouvrir un site public sans se connecter.

- Les pages peuvent apparaître dans le sitemap XML du site.
- Les moteurs de recherche peuvent indexer les pages accessibles.
- La recherche publiée, les bibliothèques, les aperçus de fichiers et les
  exports sont accessibles lorsqu'ils figurent sur la page.
- Un domaine personnalisé vérifié sert le même contenu public que l'adresse
  BaseBlocks générée.

Utilisez Public pour la documentation, les bases de connaissances et les
informations destinées au Web ouvert.

## Privé

Un site privé exige un compte BaseBlocks connecté qui appartient à l'équipe du
site.

- Un visiteur anonyme reçoit un écran d'accès générique, jamais le contenu.
- Un utilisateur connecté qui n'appartient pas à l'équipe est refusé.
- Les pages privées sont absentes des sitemaps XML et marquées
  `noindex, nofollow`.
- Le contenu, la navigation, la recherche, les bibliothèques, les fichiers et
  les exports sont tous contrôlés séparément côté serveur.
- Le passage de Public à Privé s'applique immédiatement aux nouvelles requêtes.

L'adresse authentifiée d'un site privé est :

```text
https://votre-equipe.baseblocks.dev/[identifiant-site]
```

L'accès privé utilise actuellement cette adresse BaseBlocks afin que le cookie
de session soit vérifié de façon sûre entre les sous-domaines BaseBlocks. Si un
site privé possède aussi un domaine personnalisé, celui-ci dirige les membres
vers l'adresse BaseBlocks authentifiée.

Utilisez Privé pour la documentation interne ou les informations sensibles qui
doivent rester dans l'équipe.

<Callout type="warn" title="Une URL n'est pas un contrôle d'accès">
  BaseBlocks ne propose pas actuellement de mode « accessible par lien ». Ce
  partage ne convient pas aux données sensibles, car un lien peut être
  transféré, journalisé ou exposé. L'accès par mot de passe n'est pas encore
  implémenté.
</Callout>

## Changer la visibilité

Choisissez Public ou Privé dans **Paramètres du site → Visibilité**. Ce réglage
est indépendant de l'état publié ou non publié.

Pour une fermeture stricte, choisissez Privé puis retirez le site. Le retrait
coupe toute la surface publiée sans supprimer le contenu de l'éditeur.
